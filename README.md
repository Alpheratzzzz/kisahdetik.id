## Deployment

This repository contains two parts:
- `./` — Next.js frontend app
- `./backend` — Laravel API backend

For production deployment:
1. Set the backend base URL in `NEXT_PUBLIC_API_URL` inside `./.env.example` or your production environment.
2. Configure backend CORS and stateful domains in `backend/.env.example`.
3. Deploy the Laravel backend to a PHP hosting environment with MySQL and run `php artisan migrate --force`.
4. Deploy the Next.js frontend to a Node.js-compatible host or use `npm run build` and `npm start`.

If you host the frontend separately, make sure the backend API is reachable at the URL configured by `NEXT_PUBLIC_API_URL`.
